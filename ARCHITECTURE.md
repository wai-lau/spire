**THE GAME SMOKE (owner, 2026-10-11: "add smoke tests for all basic features as commit hook"):** `scripts/spire-smoke/smoke.mjs` loads every `/aspira-*.js` the template loads, IN ITS ORDER, into one node vm over a fake DOM (`dom.mjs`: template ids pre-made, swatch colours, no WebGL, no audio, an empty fetch) whose canvas RECORDS calls, then drives the real `frame` loop: boot, 2D / low / the 3D fallback, each tower built through `placeTower` (its range, body and movement arrows must draw), a fought wave (enemies drawn, damage dealt), the boss sky spreading and full, Temporal Drive, the lives-left line, loss / win / the Ascendants, play again.
